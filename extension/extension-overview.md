# TFVC Build Tasks

Interact with Team Foundation Version Control repositories from Azure Pipelines and Azure DevOps Server builds.

The tasks can add, check in, delete, or undo files, update gated changes, and prevent automatic source synchronization.

Version 3 bundles the TFVC client object model and supports Visual Studio 2026-era authentication without depending on installed Visual Studio client assemblies. Earlier task versions remain available.

See the [documentation](https://github.com/jessehouwing/azure-pipelines-tfvc-tasks/wiki) for usage and configuration.
